# 🥐 Golden Crust Bakery — Interactive Landing Page

A responsive, visually engaging landing page for an artisanal bakery featuring custom CSS polygon clip-path scroll animations and grid layout design.

[Live Demo](https://goldencrusts.netlify.app/) 

---

## ✨ Features
- **Dynamic Scroll Animations:** Custom JavaScript calculations that manipulate CSS `clip-path` and opacity properties on scroll.
- **Responsive E-Commerce Grid:** Auto-fitting product card grid optimized for mobile, tablet, and desktop viewports.
- **Mobile Navigation Drawer:** Responsive toggle menu for smaller screens.

## 🛠️ Tech Stack
- **HTML5** (Semantic structure)
- **CSS3** (Flexbox, CSS Grid, Transitions, Clip-path, Media Queries)
- **JavaScript ES6+** (DOM Manipulation, Scroll Event Handling)
